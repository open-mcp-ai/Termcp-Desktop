## 紧凑界面增量验证

- 1280×900 工作台：右侧只有一块会话信息面板，管理与复制为小按钮。
- 收起/展开会话面板：工具条出现并可恢复完整面板。
- 最小化/展开终端：终端正文隐藏并可恢复，Shell 数据保持不变。
- 会话管理 → 关闭当前 Shell：进入正确的确认对话框，取消可返回工作区。
- 360×800：展开和收起侧栏时整页 scrollWidth 均为 360，终端最小化有效。
- 浏览器 console error/warn 为空；npm run check 通过。

## SSH 工作台与主机详情增量验证

- 默认展示开发与预发布两个主机的终端，并保留本地工作区标签。
- 连续左右、上下分屏形成 4 个窗格；会话仍为 3 个，Shell 从 4 增为 6。
- 分隔线方向键改变比例；鼠标拖动将默认 55% 调整至 63%。平铺与分屏切换保留比例。
- 平铺展示全部窗格；最大化仅显示一个，恢复后返回；收起终端进入恢复工具条。
- 模拟输入只出现在目标 Shell。移除窗格后 Shell 数量不变，添加现有 Shell 后回显仍在。
- 主机搜索与收藏筛选有效；新主机支持分组、跳板与收藏，加入当前分屏后新增一条会话。
- 编辑配置保留私钥认证选择；互相引用的跳板配置被阻止并显示循环提示。
- 新主机详情显示尚未采集监控，不套用演示主机的快照。
- 监控与 termcp 标签切换有效；焦点切换后主机身份、参数、Shell 列表和资源 URL 跟随目标。
- 收起主机详情后显示 CPU、内存和磁盘摘要，可恢复完整面板。
- 关闭最后一个 Shell 后重新打开活跃会话，创建新的 Shell，复用原会话连接。
- Core 重启后会话、Shell、转发归零，所有窗格引用清空；可创建新连接。
- 1440×1050、1280×900 桌面与 360×800 窄窗口检查无整页横向溢出。窄窗口中终端纵向排列，主机详情移到下方。
- 浏览器 console error/warn 为空。
- 中断图标向当前 Shell 写入模拟 Ctrl+C 回显，未执行真实命令。

监控仅为静态设计快照，未验证真实采集。页面状态只存内存，未验证布局持久化或跨次恢复。
